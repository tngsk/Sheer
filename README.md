# Project Sheer：テキスタイル・ジェスチャー音響システム仕様書（V1.0）

1. コンセプト＆目的1.1 プロジェクト名：Project Sheer（シアー）「Sheer（極薄の、透き通るような、さらっとした質感）」という言葉が示す通り、本プロジェクトは、テクノロジーが衣服や身体に完全に溶け込み、その存在を感じさせないほど透明（Invisible）でスマートな音響インタラクションシステムを構築することを目的とします。  1.2 目的ダンスや演奏などの身体運動を妨げない「さらっとした装着感」のウェアラブルデバイスから、腕や手首のしなやかな「身振り（ジェスチャー）」を100〜200Hzの高速ストリーミングで抽出。PC側の機械学習（ML）によってガタガタとしたデジタル的段差を一切排除した滑らかなグラデーション（知覚の連続性）へと整形し、DAW（Ableton Live, Max等）の音楽表現をシームレスに制御します。  2. システムアーキテクチャシステムは以下の3つのレイヤーで構成され、複雑なローカルビルドを排除して軽量に結合されます。  [ウェアラブル：LEAD SKIN ×2] （さらっとした皮膚感覚）
         │ （分圧回路によるアナログ電位変化）
[エッジ：M5ATOM (ESP32)] ─── 高速タイマー駆動（100〜200Hz）
         │ （USBシリアル / CSVストリーミング）
[PC / Mac：Python (scikit-learn)] ─── Sliding Window ＆ 機械学習推論
         │ （確信度を用いた滑らかなモーフィング）
[DAW：Ableton Live / Max / Pd] ─── MIDI CC / OSCによる音楽制御
3. ハードウェア仕様と回路設計3.1 ウェアラブル部（装着仕様）配置: 利き腕の前腕部に、通気性の良いさらっとした質感のバンドを巻く。  センサ: LEAD SKIN（テキスタイル伸縮センサ）を2枚縫い付け。  センサA（手のひら側）: 手首の屈曲、指の握り込み（グリップ）を主に検知。  センサB（手の甲〜外側）: 腕のひねり、前腕の回旋運動を主に検知。  3.2 回路構成（分圧 ＆ マイコン接続）M5ATOM（ESP32）のアナログ入力（ADC）ピン2chを使用し、LEAD SKINの抵抗値変化を電圧変化として読み取ります。  ルート配線詳細チャンネルA3.3V — Rfixed_A —+— LEAD SKIN A — GND → M5ATOM (G32)  チャンネルB3.3V — Rfixed_B —+— LEAD SKIN B — GND → M5ATOM (G33)  Rfixed（固定抵抗）: LEAD SKINの実測ベースライン抵抗値に合わせ、10k〜100kΩから最適値を剪定。  プロアクティブ保護（静電気対策）: 人体からの静電気突入によるM5ATOMの破壊を防ぐため、導電性繊維とマイコンピンの間に1kΩの保護抵抗を直列に挿入。または導電布の表面に薄い通常の布地を重ねるオーバーレイ構造を採用し、物理的に絶縁しつつ近接静電容量（または緩やかな圧力変化）として処理。  4. ファームウェア仕様（M5ATOM側）ループ内のディレイ（delay）による周期の揺らぎを排除し、厳密なサンプリングレートを維持するために micros() による時間管理を行います。  サンプリング周波数: 200Hz（5ms周期）  通信速度: 115200 bps（USBシリアル）  出力データフォーマット: CSV形式（カウント,chA,chB\n）  M5ATOM用ソースコード（C++）C++#include <Arduino.h>

const int PIN_CH_A = 32; // 環境に合わせてピン番号を調整
const int PIN_CH_B = 33; 

const unsigned long INTERVAL_MICROS = 5000; // 5000us = 200Hz
unsigned long next_sample_time = 0;
unsigned long sample_count = 0;

void setup() {
    Serial.begin(115200);
    pinMode(PIN_CH_A, INPUT);
    pinMode(PIN_CH_B, INPUT);
    next_sample_time = micros();
}

void loop() {
    // 厳密な時間管理によるビジーウェイト（周期の揺らぎを排除）
    if (micros() >= next_sample_time) {
        int val_A = analogRead(PIN_CH_A);
        int val_B = analogRead(PIN_CH_B);
        
        // CSVストリーミング形式で出力
        Serial.print(sample_count);
        Serial.print(",");
        Serial.print(val_A);
        Serial.print(",");
        Serial.println(val_B);
        
        sample_count++;
        next_sample_time += INTERVAL_MICROS;
    }
}
5. 機械学習 ＆ 信号処理仕様（PC側）5.1 タイムウィンドウ（Sliding Window）設計窓長（Window Size）: 500ms 〜 1000ms（動きの「状態」を捉えるための十分な時間軸）  ステップ幅（Update Interval）: 100ms（音楽的追触性を担保する時間解像度）  ※アタック対策（バイパスルート）: キックのトリガーなど、遅延が許されないイベントに対しては、100msの超短期窓を並列で走らせ、1次差分の最大値（ピーク）でダイレクトにトリガーする判定ロジックを設ける。  5.2 特徴量マトリクス各ウィンドウから以下の特徴量を抽出し、数十次元の軽量な特徴量ベクトルを生成します。  静的統計量: chA / chB それぞれの 平均値、分散、最大値、最小値。  動的統計量: 1次差分の平均絶対値（MAV）（＝動きの激しさ、スピードの指標）。テキスタイル特有のドリフト・ヒステリシス影響をキャンセルするために最重要視する。  肢体相関量: chA - chB（差分）、chA / (chA + chB)（比率）。腕の「ひねり」と「握り」の協調運動の比率を抽出。  5.3 分類モデル（分類アルゴリズム）選定: ランダムフォレスト（Random Forest）  理由: ロジスティック回帰のような線形モデルでは捉えきれない、筋肉の共収縮による非線形なジェスチャー境界（例：「AとBが同時に特定の比率で動いた時だけ『ひねりクラス』とする」など）を、少ない学習データ量で高精度に識別可能であるため。  6. インタラクション ＆ 音楽表現（DAWマッピング）本プロジェクトの核心である「さらっとスマートな接続」を具現化するため、分類結果（クラス0, 1, 2...）の単純なスイッチングではなく、推論の「確信度（Probability）」を音楽パラメータにマッピングします。  6.1 ジェスチャークラスの定義例クラス0: ニュートラル（静止・待機）  クラス1: 大きくしなやかに腕を振る（Fluid Motion）  クラス2: 小さくリズミカルに刻む（Rhythmic Tap）  クラス3: 前腕をひねる・回スンさせる（Twist）  6.2 確信度（Probability）マッピングによる知覚の連続性scikit-learn の predict_proba() を使用し、現在の身振りが「クラス3（ひねる）」である確率（0.0 〜 1.0）をリアルタイムに算出。  マッピング例: ひねり動作の確率（0.0〜1.0）をそのまま MIDI CC（音量やリバーブのWet量、フィルターのカットオフ周波数）にアサイン。  効果: 身体運動の「滑らかさ・曖昧さ」がそのまま音の連続的なモーフィングに直結し、デジタル特有の「ガタガタした切り替え感」が完全に消滅。衣服を滑らかに纏うような洗練された音楽制御が実現。  7. 運用・トラブルシューティングWindowsでのポート使用中エラー:Arduino IDEのシリアルモニタが開いていると、PC側のPythonスクリプトがCOMポートを占有できずエラーになります。実行前に必ずIDE側のモニタを閉じること。  テキスタイル特特のヒステリシス（戻り遅れ）:激しく動かした後にセンサ値が初期値に綺麗に戻らない場合は、生データの絶対値（平均値）の評価ウェイトを下げ、1次差分（動きの変化量）の特徴量ウェイトを上げるようモデルを調整すること。
